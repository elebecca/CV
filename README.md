## Selected Projects

### Red Pulse

Full-stack casino management analytics dashboard built as a personal portfolio project using synthetic data.

**Technologies:** Next.js, React, TypeScript, NestJS, Prisma, PostgreSQL, Docker, Docker Compose, Tailwind CSS, shadcn/ui

Key features include:

- Dashboard summary metrics backed by PostgreSQL data
- Revenue and Gross Gaming Revenue calculations
- Active player metrics
- Retention analysis
- Games activity tracking
- Bonus cost reporting
- System availability monitoring
- Geographic market metrics
- REST API integration between frontend and backend
- Docker-based development environment
